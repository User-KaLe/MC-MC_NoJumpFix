# MC禁止连跳/MC_NoJumpFix
# 《我的世界》长按空格连跳修复工具

## 🚀 功能亮点
- **一键运行**：无需安装环境，双击即用。
- **精准拦截**：仅限游戏生效，不影响其他程序。
- **轻量无感**：后台占用极低，专注解决手滑问题。

## 📥 下载与使用
1. 前往 [Release 页面](https://github.com/yourname/MC_NoJumpFix/releases) 下载 `MC_NoJumpFix.exe`。
2. 右键文件 → **以管理员身份运行**（必须！）。
3. 启动游戏，长按空格测试效果。

## ⚙️ 适配说明
- **Java 版**：默认支持 `java.exe`/`javaw.exe`（覆盖大多数启动器）。  
- **基岩版**：修改脚本中的进程名为 `Minecraft.Windows.exe`。  

## ⚠️ 注意事项
- 部分多人服务器可能检测为作弊工具，使用前请确认规则。  
- 若脚本未生效，请检查游戏进程名是否为 `java.exe`。
